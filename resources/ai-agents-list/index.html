✅ How to start (beginners)

  1. Start with one free agent — Manus or Genspark is easiest.
  2. Give a small, clear goal: "Hyderabad to Goa, Saturday, 4 friends, budget ₹8,000 each — best options cheppu."
  3. Watch what steps it takes — plan → act → check → repeat.
  4. Never share passwords or card details unless you fully trust the tool.

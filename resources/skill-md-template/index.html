AI Skill Template

Use this template to save instructions for a task you repeat often.

Part 1: Fill In Your Skill

Skill Title

Give your skill a clear name.

Example: Email Reply, Bug Fix Update, Reel Script.

Purpose

Explain what the skill should do and what you will provide each time.

Example: “Write a customer email reply from the message and order details I provide.”

Tone

Describe how the output should sound.

Example: Friendly, simple English. Short sentences. No jargon.

Format

List the sections in the order you want them.

Example:

  1. Subject line
  2. Three short lines
  3. Sign-off

Required Information

List the details that must always appear.

Example:

  • Customer name
  • What changed
  • New date
  • Next step

If essential information is missing, ask me one question before writing.

Output Limits

Set the length and presentation rules.

Example:

  • Under 100 words
  • Plain text only
  • No extra explanation before or after the draft

Part 2: Set Up and Improve

1. Name Your Folder

Rename skill-template to your skill name.

Use lowercase letters, numbers, and hyphens.

Example: email-reply

2. Complete Your File

Open SKILL.md.

Set its name: field to match the folder name, then fill in the sections above.

3. Add It to Claude

Claude app: Zip the skill folder and upload it through the skill settings.

Claude Code: Place the folder in ~/.claude/skills/, then invoke it with /your-skill-name.

4. Improve It Over Time

When an output needs a correction, update the relevant instructions in SKILL.md.

Adjust the tone, format, rules, or examples. Upload the updated version if you use the Claude app.

File Checklist

  • File name: SKILL.md, with capital letters.
  • Skill name: maximum 64 characters.
  • Use lowercase letters, numbers, and hyphens.
  • Do not include “claude” or “anthropic” in the skill name.

Part 3: Filled Example — Reel Script

Purpose

Write a spoken reel script from the topic I provide.

Example input: “Claude skills in 3 steps.”

Tone

  • Use natural Teluglish: Telugu sentences with common English tech words.
  • Sound like a friend explaining something.
  • Keep sentences short and easy to say aloud.
  • Start directly, without filler greetings.

Script Structure

SectionWhat to write
HookOne relatable question or bold claim. Under 15 words, delivered in the first 3 seconds.
Open loopPromise one specific thing the viewer will learn, by second 5.
BodyThree steps or points. One idea per line. Keep the explanation moving.
PayoffOne memorable line that delivers on the opening promise.
CTAOne action only: comment, follow, or save.

Required Information

Always include:

  • The topic
  • A clear connection to the intended audience
  • One concrete example
  • One number or a numbered step list

If the topic is too vague, ask one focused question first.

Never invent statistics. Mark any claim that needs checking with [verify].

Deliverables

Return these in order:

  1. Script: Under 150 words.
  2. Beat sheet: A table with the spoken line, on-screen text, and suggested visual. Keep on-screen text to four words or fewer.
  3. Alternate hooks: Three options, ranked strongest to weakest, with a one-line reason for each.

Rules

  • No emojis or hashtags in the script.
  • Spell English terms normally: AI, prompt, tool.
  • Preserve the facts I provide.
  • Avoid exaggerated promises and unsupported claims.
  • Make the script comfortable to speak aloud.
  • Use only one CTA.
  • If essential information is unclear, ask before writing.

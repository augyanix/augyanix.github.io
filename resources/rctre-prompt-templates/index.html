RCTRE Prompt Templates

Role, Context, Task, Rules, Example: copy-ready prompt templates.

RCTRE PROMPT TEMPLATES — by @augyanix
=====================================

R = Role      → Evaru answer cheyyali? (who should answer)
C = Context   → Mee situation enti? (background the AI can't guess)
T = Task      → Exactly em kavali? (one clear job)
R = Rules     → Ela kavali? (format, length, limits, do / don't)
E = Example   → Ila kavali (a sample, reference or similar case)

Note: Idi just a checklist for better results — MANDATORY kaadu.
Simple questions ki 2–3 parts chaalu. Pedda tasks ki all 5 vaadandi.


-------------------------------------
1) BLANK TEMPLATE (copy & fill)
-------------------------------------
Role: You are a [expert / role].
Context: [Who I am, what I'm working on, important background, constraints.]
Task: [The one specific thing I want you to do.]
Rules:
- [Output format, e.g. bullet points / table / code only]
- [Length, e.g. under 150 words]
- [Tone / language, e.g. simple English, Teluglish]
- [What NOT to do]
Example: [Paste a sample of what good looks like, or a similar case.]


-------------------------------------
2) CODING — BUG FIX (from the reel)
-------------------------------------
Role: You are a senior backend engineer.
Context: This is a Spring Boot project running in production. Java [version], Spring Boot [version].
Task: Fix this NullPointerException.
[Paste the stack trace and the relevant method here]
Rules:
- Show only the changed lines, with a one-line reason for each change.
- Don't change method signatures or add new libraries.
- If something is unclear, ask me before assuming.
Example: Here is a similar function from my project that follows our coding style:
[Paste the similar function here]


-------------------------------------
3) EMAIL / MESSAGE WRITING
-------------------------------------
Role: You are a professional communication coach.
Context: I need to email my manager. [Situation, e.g. I need 2 days leave next week for a family function. The sprint ends Friday.]
Task: Write the email.
Rules:
- Polite but direct, under 120 words.
- Include a short plan for covering my work.
- Give a subject line.
Example: Keep the tone like this: "Hi Ravi, quick request — ..."


-------------------------------------
4) LEARNING A NEW TOPIC
-------------------------------------
Role: You are a patient teacher who explains tech to beginners.
Context: I'm a [student / working professional] and I know [what you already know, e.g. basic Python]. I'm learning [topic, e.g. unsupervised learning].
Task: Explain [topic] so I can understand it in 5 minutes.
Rules:
- Use one everyday Indian example.
- Simple English, short paragraphs, no heavy maths.
- End with 3 quick questions to test me.
Example: Explain it the way you'd explain "supervised learning = learning with labelled answers".


-------------------------------------
5) RESUME / LINKEDIN
-------------------------------------
Role: You are a technical recruiter who screens [role] resumes.
Context: I'm applying for [job title] at [type of company]. My experience: [years, key skills, 2–3 achievements].
Task: Rewrite my resume summary and 3 experience bullet points.
[Paste current summary and bullets here]
Rules:
- Use action verbs and numbers where I have them; don't invent numbers.
- Each bullet under 25 words.
- Match keywords from this job description: [paste JD]
Example: "Reduced API latency by 40% by adding Redis caching for hot endpoints."


-------------------------------------
6) CONTENT / REEL SCRIPT
-------------------------------------
Role: You are a viral tech content creator for Instagram Reels.
Context: My audience is Indian tech fans aged 20–45. I speak Teluglish. Topic: [topic].
Task: Write a 60-second reel script.
Rules:
- Hook in the first 3 seconds.
- Short spoken lines, Teluglish, keep tech words in English.
- End with a CTA to comment a keyword.
Example: Hook style like: "Ee 5 points use cheyakapothe meku proper response raadu!"


-------------------------------------
7) DATA / EXCEL ANALYSIS
-------------------------------------
Role: You are a data analyst.
Context: I have monthly sales data for [business], columns: [list columns]. [Paste a few sample rows or attach the file.]
Task: Find the top 3 insights and anything unusual.
Rules:
- Answer in a table: Insight | Evidence | Suggested action.
- Mention if the data looks incomplete.
- Don't guess numbers that aren't in the data.
Example: "Insight: Weekend sales are 30% higher | Sat–Sun avg vs weekday avg | Run weekend offers."


-------------------------------------
QUICK TIPS
-------------------------------------
• Be specific — "fix my code" kanna "fix this NullPointerException, show only changed lines" better.
• One prompt = one main task. Pedda work ni steps ga divide cheyandi.
• Output nachakapothe, Rules lo correction add chesi malli adagandi.
• Always review the output — AI can be confidently wrong.
• Passwords, API keys, customer data, or company code you're not allowed to share — paste cheyakandi.

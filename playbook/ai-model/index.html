Cell 3 · fine-tune + save (Step 5):

python
from datasets import load_dataset
from trl import SFTTrainer, SFTConfig

data = load_dataset("json", data_files="qa.jsonl", split="train")
data = data.train_test_split(test_size=0.2, seed=42)   # 20 % kept aside = test data

trainer = SFTTrainer(
    model="HuggingFaceTB/SmolLM2-135M-Instruct",
    train_dataset=data["train"],
    eval_dataset=data["test"],
    args=SFTConfig(output_dir="my-model", num_train_epochs=3, report_to="none"),
)
trainer.train()
trainer.save_model("my-model")

Cell 4 · testing (Step 6), before vs after:

python
from transformers import pipeline
for name in ["HuggingFaceTB/SmolLM2-135M-Instruct", "my-model"]:
    chat = pipeline("text-generation", model=name)
    out = chat([{"role": "user", "content": "How should I prepare for an HR round?"}], max_new_tokens=80)
    print(name, "→", out[0]["generated_text"][-1]["content"])

Project 2 · Fine-tune a small open model (step 5, the missing step)

Time: 1-2 hours. Machine: free Colab T4 GPU recommended.

Instead of training from zero, take a small open model and teach it YOUR style of answers with your own Q&A examples. We use SmolLM2-135M-Instruct (Apache-2.0 license, tiny) and Hugging Face TRL.

Setup

Fine-tuning data (Q&A examples)

json

Mistakes beginners make

  • Training on dirty data (step 2 skipped) → the model learns the junk too.
  • Testing on the same questions it trained on → fake "100 % correct".
  • Too few examples, too many epochs → it memorises your Q&A word for word.
  • Out of memory error → lower batch_size / block_size, or switch to Colab GPU.
  • Using text you don't have the rights to.
